# أكاديمية ليان — نسخة Acode متعددة الصفحات

هذه نسخة مستقلة تستخدم **HTML وCSS وJavaScript فقط**، وتعمل في Acode من دون React أو TypeScript أو Node.js.

## الصفحات

| الملف | محتواه |
|---|---|
| `index.html` | الصفحة الرئيسية والمقدمة والخدمات الرئيسية. |
| `services.html` | جميع الخدمات والبحث والتصنيفات ونموذج الحجز. |
| `about.html` | الرؤية والرسالة والقيم والأهداف وطريقة العمل. |
| `work.html` | معرض الأعمال والصور. |
| `support.html` | الدعم والأسئلة الشائعة وأيقونات التواصل. |

## معاينة الموقع في Acode

فك الضغط، وافتح **مجلد المشروع كاملًا** داخل Acode. افتح `index.html` ثم اختر **Preview / معاينة**. انتقل بين الصفحات عبر القائمة العلوية.

## التواصل

لا يعرض الموقع رقم واتساب أو البريد الإلكتروني في الواجهة. تظهر فقط أيقونتان، وتفتحان واتساب أو تطبيق البريد مباشرة. لتعديلهما، افتح `script.js` وعدّل أول سطرين:

```js
const WHATSAPP_NUMBER = "966540047914";
const EMAIL = "alquhtanilino@gmail.com";
```

اكتب رقم واتساب بصيغة دولية، من دون علامة `+` أو مسافات.

## تغيير الصور

ضع الصور في مجلد `assets/`. صور معرض الأعمال تبدأ من `project-1.jpg` إلى `project-6.jpg`. يمكنك استبدالها مع الحفاظ على الأسماء نفسها؛ وإذا غيّرت الاسم، عدّل المسار في `script.js`.

## تعديل الخدمات والأسعار

افتح `script.js` وابحث عن `const services = [` في البداية. كل خدمة تحتوي على السعر (`price`) والاسم والوصف بالعربية (`ar`) والإنجليزية (`en`).

## الرفع المجاني على Netlify

ارفع **محتويات هذا المجلد** في Netlify، مع التأكد أن `index.html` موجود في أول مستوى من الملفات. إعداد `netlify.toml` مرفق ولا يحتاج أي أمر بناء.
